## ✨ Features

### Core Functionality
- ✅ Basic arithmetic operations (`+`, `-`, `×`, `÷`)
- ✅ Percentage calculation (`%`) — converts `50%` to `0.5` automatically
- ✅ Decimal point with smart duplicate prevention
- ✅ Clear Everything (`CE`) & Delete Last (`⌫`)
- ✅ Real-time expression history display

### Premium UI/UX
- 🎨 **Glassmorphism design** — frosted glass effect with backdrop blur
- 🌈 **Gradient accents** — vibrant orange operators and equal button
- ✨ **Smooth animations** — button press effects, hover transitions
- 📱 **Fully responsive** — adapts to mobile, tablet, and desktop

### ⌨️ Full Keyboard Support
| Key | Action |
|-----|--------|
| `0-9` | Input numbers |
| `+ - * /` | Operators |
| `%` | Percentage |
| `.` | Decimal point |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last character |
| `Escape` | Clear everything (CE) |

### Error Handling
- Prevents consecutive operators
- Blocks multiple decimals in same number
- Handles division by zero and invalid expressions gracefully
- Displays `Error` state with automatic recovery
